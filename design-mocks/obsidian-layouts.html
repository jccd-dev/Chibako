A quieter workspace for connected thought

Chibako keeps notes, links, and agent access in one private vault. The interface should give writing priority without hiding the structure around it.

Working principle

The document stays centered between two quiet utility panes. Navigation answers where the note lives. Connections explain how it relates to the vault.

  • Files remain the primary hierarchy.
  • Secondary actions move out of the writing path.
  • Wikilinks retain their existing visual language.

The note owns the workspace

Files and connections stay one action away. The central canvas gains more room for long-form writing while every existing destination remains available.

Best fit

This direction suits focused writing sessions and smaller laptop displays. It reduces persistent context, so users open side panels when they need them.

  • Maximum document space.
  • Lowest visual noise.
  • More panel switching during research.

Structure stays visible

This layout treats navigation and metadata as part of the working context. It fits users who move between many related notes throughout the day.

Best fit

Dense vault navigation makes large note collections faster to scan. The tradeoff is less room for the document and more persistent chrome.

  • Strongest information hierarchy.
  • Fastest cross-note navigation.
  • Highest visual density.
